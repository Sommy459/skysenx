Kids Tech Summer Camping

SkysenxHub's TechCamp is our summer training platform for kids and teens during holidays where we introduce them to different technologies that will help shape their career paths. It is an annual event aimed at inculcating kids and teens with the technological skills required in the 21st century.

This year's TechCamp 2025 runs from July 30th to August 29th.

5 week Camping
6 Courses
2 Sessions

AI for Students (13+)

fees: ₦100,000

Step into the future with Artificial Intelligence! This course introduces kids to the exciting world of AI - what it is, how it works, and how it's shaping our lives today. Students will learn the basics of AI concepts and prompt engineering, discovering how to communicate effectively with AI tools. They'll explore real-world AI applications and popular AI frameworks used by developers around the world.

The course also focuses on AI-assisted learning, showing how AI can help with studying, creativity, and problem-solving. Through fun activities like Vibe Coding, students will get hands-on experience building simple AI-powered solutions.

For their capstone project, each student will design and develop a personalized AI agent - an intelligent helper that can perform tasks or answer questions - showcasing everything they've learned about creating with AI. This project empowers them to harness AI creatively and responsibly.

Curriculum

  • Introduction to Artificial Intelligence and how it works
  • Learn prompt engineering to communicate with AI tools
  • Explore real-life AI applications in daily use
  • Discover popular AI tools and frameworks for beginners
  • Use AI for creative writing, problem-solving, and learning
  • Experiment with Vibe Coding and AI-powered tools
  • Build and present a mini AI agent as a capstone project

Requirements

  • Age 13 and above
  • A personal laptop with basic knowledge of its operation
  • Basic reading and writing skills

Curriculum

  • How the web works and what makes up a website
  • Creating page structure with HTML
  • Styling websites using CSS
  • Building responsive layouts for phones and desktops
  • Adding interactivity with JavaScript
  • Publishing a complete website project

  • Interest in design, logic, and problem-solving

Programming & Animation (Micro:Bit & Circuit Playground) (13+)

fees: ₦50,00

Bring code to life with lights, sounds, and motion! In this hands-on course, kids will explore the exciting world of physical computing using the BBC Micro:Bit and Adafruit Circuit Playground. They’ll learn how microcontrollers work and how to program them using both block-based tools (Microsoft MakeCode) and text-based coding (MicroPython). Students will build fun, interactive projects that respond to inputs like buttons, sensors, and motion—creating animations, games, and even musical effects using the built-in features of these tiny but powerful boards. Along the way, they’ll gain valuable programming skills and a deeper understanding of how software and hardware work together. For their capstone project, each student will design a creative interactive system—such as a reaction timer, animated badge, or musical light display—using either Micro:Bit or Circuit Playground. It’s a fun, practical way to explore programming, electronics, and real-world problem-solving

Curriculum

  • Learn how microcontrollers power smart devices
  • UUnderstand how the Micro:Bit and Circuit Playground work
  • Code with drag-and-drop blocks using MakeCode
  • Master basic programming concepts step-by-step
  • Get started with text-based coding using MicroPython
  • Write MicroPython programs for real-world tasks
  • Control lights, buttons, and sensors through I/O ports

Requirements

  • Age 11 and above
  • A personal laptop with basic knowledge of its operation
  • Basic reading and writing skills

Curriculum

  • Introduction to creative coding with Scratch
  • Build interactive games using drag-and-drop blocks
  • Create animations and visual effects
  • UTell stories with characters, backgrounds, and scripts

  • Exporting design for digital and print use
  • Develop logic and sequence skills through fun challenges

Scratch Programming(8+)

fees: ₦40,000

Turn imagination into interactive fun with Scratch! Kids will dive into this beginner-friendly programming platform where they can build games, animations, musical stories, and more using simple drag-and-drop code blocks. They’ll develop logical thinking, storytelling, and creative skills by designing characters, scenes, and sounds, including adding music and sound effects to their projects. Scratch helps make programming approachable and enjoyable for young learners. For their capstone project, each student will create a unique Scratch project—whether it’s a game, animated story, or a musical performance—fully designed and coded by them. This project encourages creative expression and solidifies their understanding of programming concepts in a playful way.
